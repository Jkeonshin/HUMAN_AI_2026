Docker로 Jenkins 설치 및 초기 설정


1. Jenkins 컨테이너 실행

docker run -d \
  --name jenkins \
  --restart=always \
  --user root \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  -v /var/run/docker.sock:/var/run/docker.sock \
  jenkins/jenkins:lts-jdk17

2. 실행확인 
#docker ps
9fd498201ef5   jenkins/jenkins:lts-jdk17  

$> docker exec jenkins whoami    root 확인
$> docker exec -it -u root jenkins bash  젠킨스 컨테이너 실행
$> docker ps   다른 우분투에서 확인  (젠킨스 컨테이너 실행 확인)

5. 초기 관리자 비밀번호 확인
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword

6. Jenkins 브라우저 접속
http://localhost:8080
